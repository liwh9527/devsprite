📋 项目概述

DevSprite 是一个轻量级的 Windows 桌面小组件，灵感来源于 macOS 上的 CodeIsland 项目。 它通过桌面悬浮窗的形式，实时显示 AI 编程工具（如 Claude Code）的运行状态， 让开发者无需频繁切换窗口就能掌握 AI 代理的工作进度。

✨ 核心功能

📊

实时状态监控

监听 Claude Code 的会话状态，包括空闲、思考、工具调用、等待输入等状态，实时更新显示

🔐

权限管理

从小组件直接批准或拒绝 Claude Code 的权限请求，无需切换到终端窗口

📜

工具调用历史

显示当前会话中的工具调用列表，包括文件读取、搜索、编辑等操作

🎯

一键跳转

点击会话可跳转到对应的终端窗口，快速定位工作位置

🖥️

系统托盘集成

托盘图标显示当前状态，右键菜单提供快速操作，支持全局快捷键

🎨

自定义吉祥物

支持用户替换吉祥物图片，可用 AI 生图工具生成自己喜欢的 Q 版形象

📅 开发计划

预计总开发周期 10-15 天

Phase 1：项目搭建 + 基础 UI

初始化 Tauri 项目，搭建前端框架，实现基础的悬浮窗 UI 和样式

预计 2-3 天

Phase 2：IPC 通信 + Claude Code 钩子

实现 Named Pipe 监听，配置 Claude Code 钩子，实现事件数据解析

预计 3-4 天

Phase 3：状态显示 + 权限管理

实现状态实时更新，工具调用列表，权限请求弹窗和操作

预计 2-3 天

Phase 4：吉祥物系统 + 动画

实现吉祥物状态切换，动画效果，支持自定义图片替换

预计 2-3 天

Phase 5：打包发布 + 文档

配置打包流程，编写 README 和使用文档，发布到 GitHub

预计 1-2 天
