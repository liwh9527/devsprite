# DevSprite 吉祥物角色设定

## 角色描述 (English Prompt)

### 核心特征 (Core Features)
```
A cute chibi kawaii mascot creature, round blob-shaped body, light lavender-blue skin color,
two small pink-purple striped horns on top of head, a striped tail (alternating lavender and purple),
round black bead-like eyes, soft pink blush marks on cheeks, tiny stubby arms/legs,
minimalist cartoon style, 3D soft render, gradient purple-gray background.
```

### 各状态描述

#### Idle - 空闲/睡觉
```
A cute chibi kawaii mascot creature, round blob-shaped body, light lavender-blue skin,
two small pink-purple striped horns, striped tail, eyes closed peacefully with a gentle smile,
sleeping peacefully with "zzz" floating above head, soft pink blush marks, tiny stubby arms resting,
3D soft render, cozy atmosphere, gradient purple-gray background.
```

#### Active - 活跃/有灵感
```
A cute chibi kawaii mascot creature, round blob-shaped body, light lavender-blue skin,
two small pink-purple striped horns, striped tail, sparkling star-like eyes full of excitement,
wide happy smile, a glowing yellow lightbulb floating above head, tiny stubby arms in excited pose,
3D soft render, warm glowing light effect, gradient purple-gray background.
```

#### Working - 工作中
```
A cute chibi kawaii mascot creature, round blob-shaped body, light lavender-blue skin,
two small pink-purple striped horns, striped tail, big sparkly eyes with star-like reflections,
cheerful expression with open mouth smile, tiny stubby arms in working pose,
3D soft render, bright and energetic mood, gradient purple-gray background.
```

#### Waiting - 等待
```
A cute chibi kawaii mascot creature, round blob-shaped body, light lavender-blue skin,
two small pink-purple striped horns, striped tail, soft round eyes looking slightly upward,
gentle content smile, blushing cheeks, tiny stubby arms, holding a small green sprout/leaf,
3D soft render, patient calm mood, gradient purple-gray background.
```

#### Error - 错误
```
A cute chibi kawaii mascot creature, round blob-shaped body, light lavender-blue skin,
two small pink-purple striped horns, striped tail, dizzy spiral eyes, wavy unsettled mouth,
flustered expression, small sweat drops, 3D soft render, slightly confused mood,
gradient purple-gray background.
```

## 角色固定属性

| 属性 | 值 |
|------|-----|
| 种类 | Q版卡通小怪兽 |
| 体型 | 圆润blob状，短胖比例 |
| 主色 | 浅薰衣草蓝 (#B8C4F0 附近) |
| 角 | 头顶两侧各一个，粉紫渐变+条纹 |
| 尾巴 | 同色系条纹尾巴 |
| 眼睛 | 黑色圆珠眼，有星形高光 |
| 腮红 | 脸颊粉色腮红 |
| 四肢 | 短小圆润的 stubby 手脚 |
| 风格 | 3D soft render / 皮克斯风 / Q版 |
| 背景 | 紫灰渐变（不要复杂场景） |

## 使用说明

生成新状态图时，替换英文 prompt 中的表情/动作描述部分，保持核心特征不变。
